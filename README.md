# AI Resume Screening and Skill Matcher using Trie and AVL Tree

An AI-based Resume Screening and Skill Matching System that automates the preliminary recruitment process by analyzing candidate resumes and matching their skills with job requirements.

The project uses **Trie and AVL Tree data structures** to improve the efficiency of skill searching, candidate management, and ranking.

### Key Features
- **Resume Processing:** Extracts candidate information and skills from uploaded resumes.
- **Skill Identification:** Identifies technical skills using a predefined skill database.
- **Trie Implementation:** Enables efficient skill insertion, searching, and prefix matching.
- **Skill Matching:** Compares candidate skills with the required skills in a job description.
- **Match Score Calculation:** Calculates the percentage of matching skills.
- **Missing Skill Identification:** Displays skills that candidates need but do not possess.
- **AVL Tree Implementation:** Maintains candidate records in a balanced tree structure.
- **Candidate Ranking:** Ranks candidates based on their skill-match scores.
- **Performance Analysis:** Evaluates insertion time, searching time, and matching efficiency.

### Data Structures Used
1. **Trie:** Used for efficient storage and retrieval of skill keywords, supporting search and prefix matching.
2. **AVL Tree:** Used for balanced candidate record management and efficient searching, insertion, and deletion.

### Project Objective
The main objective is to reduce the time and manual effort involved in resume screening by providing an automated system that identifies suitable candidates based on their technical skills and job requirements.
